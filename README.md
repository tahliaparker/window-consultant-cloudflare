# Window Consultant — Cloudflare Pages

Window Consultant is an independent online publication
covering window care, glass maintenance, repairs,
and practical home improvement.

## Website

This repository contains the Cloudflare Pages edition
of Window Consultant.

## Content

Articles are synchronized automatically from
GitHub Issues in the window-consultant repository.

## Publishing

GitHub Actions generates the website every 30 minutes
and commits updated HTML files to the dist directory.

Cloudflare Pages deploys the generated website
automatically when changes are pushed to the main branch.

## Technology

- Python
- HTML and CSS
- GitHub Actions
- Cloudflare Pages
